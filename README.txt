PRABHAT & NIDHI — WEDDING INVITATION WEBSITE
================================================

DETAILS
Date: Saturday, 12 December 2026
Starts: 7:00 PM IST
Ceremonies: Ring Ceremony, Haldi and Wedding Ceremony
Venue: The Park / The Park Club & Resort, Itarsi, Madhya Pradesh

OPEN IT
Open index.html in any modern browser, ideally while connected to the
internet so Google Fonts and externally hosted venue photographs can load.

PUBLISH IT ON NETLIFY
1. Go to https://app.netlify.com/drop
2. Extract the provided ZIP if necessary.
3. Drag the entire 'prabhat-nidhi-wedding' folder into Netlify Drop.
4. Netlify will provide a public URL to share.

WHAT WORKS
- Tap the wax seal to reveal the invitation
- Automatically updating countdown to 12 Dec 2026 at 7 PM IST
- Mobile responsive sections and navigation
- Ring Ceremony, Haldi and Wedding details (all same evening)
- Actual hotel/resort photos in the venue gallery (loaded from public listings)
- Get directions opens a Google Maps search for the resort
- Add to calendar downloads a valid .ics calendar file
- RSVP prepares a WhatsApp message (does not store user data)
- Share invitation opens native sharing or copies the invite message

RSVP PHONE
The owner has not supplied the family's phone number. The WhatsApp RSVP
therefore lets the guest choose a recipient. For direct RSVP to a host,
edit script.js and set RSVP_WHATSAPP_NUMBER = '91XXXXXXXXXX' (digits only).

IMPORTANT
- Ceremony-specific start times were not provided, so none are fabricated.
- Calendar files need an end time. The downloadable .ics file uses a one-hour
  temporary block; guests can adjust it if needed. This is not an event end time.
- Before public deployment, confirm with the resort that the listed address
  and photos refer to your booked function location.
- Venue photography is loaded from MakeMyTrip and EaseMyTrip listing URLs;
  they own or license their imagery. Third-party hotlinking may be restricted,
  and photographers/resorts may require permission to republish. Ideally,
  obtain approved venue photos and replace these image sources with your
  own local licensed image files in assets/ for long-term reliability.
- The website is static and uses no database; the RSVP is a prepared message,
  not an automatic submission.

EDIT TEXT
Look in index.html for names, descriptions and event details. All files are
editable, and you do not need a build system or Node.js to publish.
